arbya-chat-sdk

Lightweight TypeScript & JavaScript SDK for real-time Arabic WebSocket rooms, presence events, and regional channel discovery.

Installation

npm install arbya-chat-sdk

Quick Start

import { ArbyaChatClient } from 'arbya-chat-sdk';

const client = new ArbyaChatClient({
  endpoint: 'https://arbya.chat',
  region: 'saudi'
});

const rooms = client.getRegionalRooms();
console.log(rooms);
